# bonbama-mcp 🇮🇷

سرور MCP **فقط‌خواندنی** و غیررسمی برای [بن‌باما](https://bonbama.ir) — پلتفرم تخفیف گرگان: کسب‌وکارها، کدها و کمپین‌های تخفیف، دسته‌بندی کسب‌وکارها و مقالات مجله. همهٔ داده‌ها **به‌صورت زنده** از صفحات عمومی بن‌باما خوانده می‌شوند — هیچ چیزی هاردکد نشده است.

> وابسته به بن‌باما نیست. ساخته‌شده برای ثبت در هاب MCP بازار — راهنمای میزبانی: [DEPLOY.md](DEPLOY.md)

## برای ایجنت‌های هوش مصنوعی

**محلی (stdio)** — به کانفیگ MCP Client اضافه کنید:

```json
{
  "mcpServers": {
    "bonbama": {
      "command": "uvx",
      "args": ["bonbama-mcp"]
    }
  }
}
```

یا اجرای محلی: `python -m bonbama_mcp.server` (نیازمند `mcp<2`، `httpx`، `uvicorn`).

**میزبانی‌شده (streamable HTTP)** — برای کلاینت‌هایی که به سرور راه‌دور وصل می‌شوند:

```
https://api.bonbama.ir/mcp
```

اندپوینت MCP روی `/mcp` است (streamable HTTP، بدون state — نیازی به چسبندگی نشست نیست)؛ بررسی سلامت روی `/health`. راهنمای میزبانی: [DEPLOY.md](DEPLOY.md).

## ابزارها

| ابزار | توضیح |
|------|-------|
| `bb_search_businesses` | جستجوی کسب‌وکارها با کلیدواژه و/یا دسته — `query`، `category`، `limit` |
| `bb_get_business` | جزئیات کامل یک کسب‌وکار — `slug` (مثل `testino`، `takchh`): توضیح، شهر، آدرس، امتیاز، دسته، کمپین‌های فعال با تخفیف و انقضا، و کدهای تخفیف منتشرشده در صفحه |
| `bb_list_categories` | همهٔ دسته‌های کسب‌وکار با نام فارسی و تعداد کسب‌وکار/کمپین |
| `bb_search_discounts` | جستجوی کمپین‌های تخفیف فعال در کل سایت — `query` (خالی = کمپین‌های محبوب) |
| `bb_search_articles` | جستجوی مجلهٔ بن‌باما (راهنماها، بهترین‌های گرگان) — `query` |
| `bb_health` | بررسی در دسترس بودن bonbama.ir در همین لحظه |

نکته‌ها:
- کمپین‌ها، کدها، قیمت‌ها و تاریخ‌های انقضا در هر فراخوانی زنده از صفحه خوانده می‌شوند و تغییر می‌کنند؛ همیشه `fetched_at` را گزارش کنید و به کاربر بگویید قبل از خرید در صفحهٔ کسب‌وکار بررسی کند.
- کدهای صریح (مثل `OFF50`) از متن خود صفحهٔ کسب‌وکار می‌آیند. بعضی کمپین‌ها نیاز دارند کاربر در بن‌باما دکمهٔ «دریافت کد» را بزند (رایگان، نیازمند حساب رایگان) تا کد/QR شخصی‌اش ساخته شود — آن کدها شخصی‌اند و اینجا هرگز برگردانده نمی‌شوند.
- منابع داده: سایت‌مپ‌ها + صفحات عمومی جستجو، کسب‌وکار، دسته و مقالهٔ بن‌باما — بدون کلید، بدون لاگین، فقط‌خواندنی. این سرور هیچ چیزی روی بن‌باما نمی‌نویسد.
